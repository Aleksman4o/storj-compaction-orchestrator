Как получить multinode key

Ключ создаётся самой нодой и записывается в её базу. Для Docker:

docker exec -it <container> /app/bin/storagenode issue-apikey --config-dir /app/config --identity-dir /app/identity

Для установленного бинарника:

storagenode issue-apikey --config-dir <config-dir> --identity-dir <identity-dir>
ВажноНа ноде должен быть включён hashstore.compaction.manual-log-compaction: true. Dashboard-порт должен быть доступен серверу orchestrator.
О ключахКлючи хранятся только на backend в orchestrator.db с правами 0600 и никогда не возвращаются браузеру.
